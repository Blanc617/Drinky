# 셀프 주량 디텍터 - 프로젝트 계획서

## 개요

술자리에서 "나 안 취했어"를 데이터로 반박하는 소셜 음주 측정 웹앱.  
술 마시기 전 기준선 측정 → 음주 중 재측정 → 변화량으로 취한 정도 수치화.

---

## 기술 스택

| 항목 | 기술 |
|------|------|
| 프레임워크 | Next.js |
| 배포 | Vercel |
| DB | Supabase |
| 인증 | Supabase Auth (구글 소셜 로그인) |
| 발음 분석 | Web Speech API (브라우저 내장) |
| 균형 측정 | DeviceOrientation API (브라우저 내장) |
| 비용 | $0 |

---

## MVP 범위

### 1차 MVP (현재 목표)
- 기준선 측정 (반응속도, 인지, 발음, 균형)
- 음주 후 재측정
- 취함 단계 판정 (7단계)
- 과거 측정 기록 저장 및 조회
- 구글 소셜 로그인

### 2차 MVP (추후)
- 복합 동작 영상 분석 (AI Vision API)
- 소셜 기능 (친구 비교, 공유)

---

## 핵심 기능

### 1. 기준선 측정
술 마시기 전 4가지 항목을 측정해 개인 기준값 저장.

| 항목 | 측정 방법 |
|------|-----------|
| 반응속도 | 화면 자극에 탭하는 시간 측정 (ms) |
| 인지 | 숫자 기억, 단어 문제 등 (정답률 %) |
| 발음 | Web Speech API로 지정 문장 인식 정확도 (%) |
| 균형 | DeviceOrientation API로 자이로스코프 수치 측정 (초) |

### 2. 테스트 뱅크
- 학습 효과 방지를 위해 유형은 동일하게, 매번 내용은 다르게 출제

### 3. 취함 단계 판정
기준선 대비 재측정 점수의 가중 평균으로 최종 점수 산출.

| 단계 | 이름 | 기준선 대비 |
|------|------|------------|
| 1단계 | 완전 멀쩡 | 95~100% |
| 2단계 | 알딸딸 | 80~94% |
| 3단계 | 기분 좋음 | 65~79% |
| 4단계 | 슬슬 취함 | 50~64% |
| 5단계 | 많이 취함 | 35~49% |
| 6단계 | 필름 위험 | 20~34% |
| 7단계 | 완전 만취 | 0~19% |

### 4. 데이터 저장
- 구글 로그인으로 본인 계정에 기준선 및 측정 기록 저장
- 다음 술자리에서도 과거 데이터 조회 가능
- 각자 본인 폰으로 접속해서 사용

---

## 사용 시나리오

```
술자리 전
1. 각자 본인 폰으로 링크 접속
2. 구글 로그인
3. 기준선 측정 (첫 방문 시) 또는 기존 기준선 불러오기

술자리 중
4. 재측정 진행
5. 취함 단계 확인
6. 친구들과 결과 비교
```

## 테스트 상세 설계

### 반응속도
- 화면에 초록/빨간 원이 랜덤하게 등장
- 초록 원 → 탭, 빨간 원 → 탭하면 안됨
- 반응시간(ms) + 오탭 횟수 함께 측정
- 예측 탭 방지 + 인지 능력 동시 측정

### 인지
- 숫자 3~5자리를 보여준 후 역순으로 입력
- 예) 3-7-2 표시 → 2-7-3 입력
- 정답률(%) 측정, 매번 다른 숫자 출제

### 발음
- 잘 알려진 한국어 어려운 문장 랜덤 출제
- 예) 간장공장공장장, 경찰청 철창살, 내가 그린 기린 그림 등
- Web Speech API 인식 결과와 원문 비교해 정확도(%) 측정

### 균형
- 폰을 손에 들고 한 발로 10초 서있기
- DeviceOrientation API로 기기 흔들림 측정
- 흔들림이 적을수록 높은 점수

### 취함 판정 가중치
- 반응속도 25% + 인지 25% + 발음 25% + 균형 25%
- 4가지 항목 균등 반영

### 기준선 측정 시점
- 매번 술자리 전 재측정 가능 (그날 컨디션 반영)
- 기존 기준선이 있으면 불러와서 업데이트 또는 유지 선택 가능
